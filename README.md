# AI 应用产品经理的方法论与实践笔记

> 仓库：`ai-lab` · 作者：AI 产品经理（作品集作者）· 更新：2026-11
> 这五篇笔记只写一件事：**把 AI 产品从"能生成"做到"可交付"的过程中，那些可以复用的判断。**
> 读者：AI 产品经理面试官（快速判断方法论与判断力），以及做 AI 应用 / Agent / 内容产品的同行（可复用的方法与坑）。

这套笔记来自我独立负责（或深度参与）的三个 0→1 项目，以及 2022–2025 年两段 B 端产品与中台经历：

- **源引 GEO**：面向中小企业的品牌生成式引擎优化（GEO）产品，Next.js 全栈 + 大模型 + 浏览器扩展。已上线免费内测；2026.10 做小范围推广与邀请试用后，因效果与商业化未达预期，项目阶段性中止，留下的是 GEO 方法论与内容 Agent 工作流。
- **阅记（Chinese Rose）**：纸质书笔记整理助手，微信小程序（uni-app + Vue 3 + TS）+ Go 后端。完成上线与小范围内测，后理性止损。
- **颜配（YanPei）**：AI 肤质检测与推荐 App（Flutter + Go）。完成 MVP，未正式上线，这里只做工程复盘，不单独成篇。
- **B 端产品与中台**：一线互联网公司企业协作产品的服务端研发（权限方案、薪酬自定义字段）；在线教育公司三大中台（动态配置 / 流控 / 消息队列，研发兼产品）。

> 本仓库**不含任何客户/合作方信息，也不含公司内部文档、生产环境信息与个人联系方式**。全部客户/合作方均匿名化；不放客户数据截图；不摘录第三方材料原文；不公开 Prompt 全文。

## 建议阅读顺序

**15 分钟版（面试官快速浏览）**：README → 01 → 02 → 05。这三篇分别对应"能不能度量效果""能不能保证交付质量""会不会做需求判断"。

**按问题读**：

- 你想看 **AI 产品怎么定指标** → 01；
- 你想看 **AI 生成质量怎么验收** → 02；
- 你想看 **一个人怎么把 AI 用成生产力** → 04；
- 你想看 **产品基本功与 B 端判断力** → 05；
- 你想看 **OCR/多模态流水线的工程化** → 03。

**面试前速览（5 个判断）**：

1. 不可解释的总分不是指标，只是叙事工具；指标要能指导下一步动作。
2. 评测先于自动化。没定义"什么算好"，自动化只会更快地生产噪声。
3. OCR 的价值不在"识别得多准"，而在"识别之后能不能被结构化和复用"。
4. AI 协作的瓶颈在上下文管理和验收标准，不在模型能力。
5. 需求洞察是减法；B 端产品化是把边界说清，让业务方能自助。

## 统一的事实口径与边界

写方法论文档最怕把"没验证的东西"写成结论。以下是我对所有项目事实的统一口径：

- **源引 GEO**：已上线免费内测，跑通"注册 → 品牌资料 → 选题预检 → 生成 → 编辑 → 草稿箱同步 → 真人探针实测"主路径；2026.10 阶段性中止，**无付费、无营收、未完成规模化验证，也未证明 GEO 效果提升**。
- **阅记**：完成上线与小范围内测，随后因价值假设失效主动止损；**无商业化、无规模用户**。
- **颜配**：完成 MVP，**未正式上线**；这里只谈工程与流程，不谈市场结论。
- **B 端经历**：只呈现我负责的部分与方法，不公开内部文档、客户名称与系统实现细节；文中的结果数字来自我在该范围内的工作记录。
- **所有数字**：来自项目自有文档、实验记录或工作记录；小样本比率必须带 n 看，不当作普适结论，也不写成"提升 X%"。
- **没做的验证**：没有 A/B 对照实验，没有统计意义上的因果证明；凡是"未验证"，文中会直接写"未验证"。
